# StudyCards

StudyCards is a web application designed to help students study and review information using digital flashcards.

## Features

- Study and review flashcards
- Simple interface for learning
- Web-based access

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- npm

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Raheemkdk/studyCards.git
   ```

2. Navigate into the project directory:

   ```bash
   cd studyCards
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm run savage
   ```

5. Open your browser and visit:

   `http://localhost:3000`
